# Pruebas incluidas

Las pruebas unitarias ejecutables de la web están junto a su lógica en `apps/web/client/src/lib` para que evolucionen con el código que protegen. Esta carpeta conserva el plan de pruebas y sirve como punto de entrada para equipos que prefieren centralizar su documentación de validación.

Consulta [docs/TESTING.md](../docs/TESTING.md) para los comandos, alcance y lista manual de aceptación.
